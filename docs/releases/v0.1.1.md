# Plugin Runtime 0.1.1

Runtime and chart 0.1.1 add bounded registration metadata and legal-notice
layers to the generic native-package envelope. Existing package types,
publisher verification, plugin protocol and manifest schema remain compatible.

Packages may carry `registration-manifest.json` as
`application/vnd.stellwerk.plugin.metadata.v1` and root `LICENSE` plus files
under `licenses/` as `application/vnd.stellwerk.plugin.license.v1`. Each file
retains its original path and bytes as a signed plain-file OCI layer.
Unknown media types, unsafe or conflicting paths, duplicate files, traversal,
archive annotations and exceeded limits fail closed before package pulling.
Metadata is limited to one file and 256 KiB. Legal content has a 1 MiB per-file,
16 MiB aggregate and 512-file bound. Existing complete-package limits remain.

Upgrade the digest-pinned runtime image before installing packages with these
new layer types. Runtime 0.1.0 rejects them at `verify-envelope`; returning to
0.1.0 therefore requires a compatible earlier package. Select the runtime,
chart, package and offline-bundle image set together. No automatic plugin
package or database rollback is implied by a Helm rollback.

Official builds use Go 1.26.10 and the normal pinned source-vulnerability check.
The installation and publication toolchain retains official ORAS 1.3.4 and
Cosign 3.1.3. Known findings in these separately distributed third-party
executables remain; this release does not describe them as vulnerability-free.
The [release-specific third-party disposition](vendor-disposition-v0.1.1.md)
records exact artifact roles, digests, historical symbol findings and the
3 November 2026 coordinated-release acceptance. No third-party pin is upgraded here.

This release contains the generic runtime, native archives and Helm chart.
It does not include or publish any commercial plugin package.
