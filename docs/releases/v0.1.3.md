# Plugin Runtime 0.1.3

Runtime and chart 0.1.3 allow `replicaCount: 0` through the chart values schema.
The chart already renders zero replicas; the schema previously refused that
explicit operator input. Negative counts remain invalid.

Use zero replicas to stop runtime and UI Pods, including during a plugin
migration. Services and workload identity remain configured. An enabled
migration Job still runs, and an enabled persistence claim remains available
while the runtime is stopped. Restore the intended replica count to serve
requests again. Zero replicas provide no runtime or UI availability.

The application runtime implementation, package protocol, publisher verification
and transport behavior are unchanged. Official builds advance to Go 1.26.11
to address [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859) in net/http. Existing packages remain compatible. This
release does not change plugin data or make Helm rollback a database recovery
mechanism.

The coordinated release still builds the runtime image, native archives and
chart from the new source identity through the normal qualification, provenance,
SBOM, signature and publication gates. Both native Linux architectures retain
their full CI and installation tests. No application dependency changes.
